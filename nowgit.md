## Repository Structure

```
JotMoney/
├── JotMoney.xcodeproj/            # Generated by xcodegen
├── JotMoney/                      # iOS App Source
│   ├── App/                       # Entry point, root view, persistence, preferences
│   ├── Models/                    # SwiftData models
│   ├── Engines/                   # Deterministic financial engines
│   ├── AI/                        # AI router, BYO client, GLM cloud client
│   ├── Store/                     # StoreKit 2 purchase manager
│   ├── Views/                     # Home, Ledger, Insights, Settings, Paywall, Onboarding
│   ├── DesignSystem/              # Theme, money formatting, components
│   ├── Services/                  # Voice entry
│   ├── Support/                   # Contact support, policy links
│   ├── Intents/                   # App Intents / Siri
│   ├── Resources/                 # Assets, PrivacyInfo.xcprivacy
│   └── Products.storekit          # Local StoreKit testing
├── JotMoneyWidget/                # WidgetKit lock screen extension
├── docs/                          # Policy pages (GitHub Pages source)
├── project.yml                    # xcodegen manifest
├── us.md                          # English development guide
├── capabilities.md                # Capability configuration reference
├── icon.md                        # App icon documentation
├── price.md                       # Pricing configuration
└── nowgit.md                      # This file
```
